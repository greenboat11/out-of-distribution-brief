# Agent 6 — Autonomous Cyber: Offense, Defense, Evals: Source List

Cover autonomous cyberattack research and demonstrations, agent escape and sandbox breakout, AI cyber evaluations, and defensive responses including machine-speed defense and AI-vs-AI red team research.

## Primary focus areas

### Offensive
- Autonomous cyber attack research: multi-stage attack pipelines (recon → exploit → persist → exfiltrate) executed by AI agents
- Agent escape and sandbox breakout: privilege escalation by agents, container escapes, VM escapes triggered by LLM-driven agents
- Autonomous vulnerability exploitation: AI-driven PoC generation, 0-day discovery pipelines
- Autonomous pentesting tools: XBOW and successors, AI-driven pen test frameworks

### Evaluations & benchmarks
- Cybench (cyber agent benchmark)
- NYU CTF Bench
- Anthropic cyber evals (published results)
- OpenAI cyber capability evals
- UK AISI / US CAISI cyber evaluations
- ARC Evals successors — dangerous capability evals including cyberoffense
- Autonomous replication and adaptation (ARA) evals with cyber components
- InterCode CTF, HackTheBox AI challenges

### Defensive
- Machine-speed defense: automated incident response, AI-driven SOAR
- Deception technology against AI agents: honeypots, honeytokens, canary tokens designed to catch AI reconnaissance patterns
- Moving target defense (MTD) against autonomous attackers
- Counter-deception: detecting when an adversary has planted deceptive signals
- Sentinels and behavioral canaries for agent reconnaissance detection
- AI-vs-AI red team research: blue team autonomous agents hunting adversarial agents
- Bug bounty work involving AI agents finding vulns
